# Security Policy

## Supported Versions

We currently provide security updates for the following versions of Attendance Hub:

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ Yes |
| < 1.0.0 | ❌ No |

## Reporting a Vulnerability

We take the security of Attendance Hub seriously. If you discover a security vulnerability, please do not disclose it publicly. Instead, follow these steps:

1. **Email us**: Send a detailed report to [itsmebk2007@gmail.com](mailto:itsmebk2007@gmail.com).
2. **Include details**: Provide a clear description of the vulnerability, steps to reproduce it, and any potential impact.
3. **Wait for a response**: We will acknowledge your report and work on a fix as soon as possible.

We appreciate your help in keeping Attendance Hub secure!
